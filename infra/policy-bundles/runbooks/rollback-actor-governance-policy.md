# Actor-Governance Policy Bundle Rollback Runbook

## Purpose
Restore the previous known-good actor-governance policy bundle if a rollout causes incorrect sanctions, actor-class parity drift, or policy API errors.

## Preconditions
- Deployment artifacts were generated by `scripts/deploy-policy-bundle.cjs`.
- A previous bundle exists in `infra/policy-bundles/releases/<environment>/<version>/bundle.json`.
- Incident commander approved rollback.

## Rollback Steps
1. Inspect current pointer:
   - `cat infra/policy-bundles/releases/<environment>/current.json`
2. Identify rollback target from either:
   - `rollback.previous_bundle_version` in the deployed bundle metadata.
   - `observed_previous_version` in `rollback.json` in the current version artifact.
3. Validate rollback target bundle:
   - `node scripts/validate-policy-bundle.cjs --bundle infra/policy-bundles/releases/<environment>/<target-version>/bundle.json`
4. Re-deploy target bundle as rollback action:
   - `node scripts/deploy-policy-bundle.cjs --bundle infra/policy-bundles/releases/<environment>/<target-version>/bundle.json --environment <environment> --output-dir infra/policy-bundles/releases`
5. Confirm pointer update:
   - `cat infra/policy-bundles/releases/<environment>/current.json`
6. Capture incident evidence:
   - Attach `deployment-record.json`, `rollback.json`, and validator output to incident ticket.

## Success Criteria
- `current.json` points to the rollback target version.
- Sanction parity checks pass after rollback.
- Error rate and appeals spike return to baseline.

## Post-Rollback Follow-up
- Freeze new policy promotions for the impacted environment.
- Open corrective policy-bundle PR with root-cause summary.
- Add a regression check for the failure mode.
