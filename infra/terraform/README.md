# Terraform (reference only)

> **NOT THE TESTNET DEPLOYMENT PATH.** The WRFCoin testnet is built locally and deployed
> from `testnet/` to the N5 Pro over SSH; images are never pushed to a registry. Nothing in this
> directory is used, tested or validated for the testnet. Do not run `terraform apply` against the testnet
> or treat it as the way to deploy this network.

See `testnet/` and `testnet/docker-compose.override.yml` for the real deployment inputs.
